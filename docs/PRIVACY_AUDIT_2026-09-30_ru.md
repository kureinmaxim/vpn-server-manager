# Проверка приватности — 30.09.2026

## Подтверждённое раскрытие в Git

В локальной истории веток, включая ссылки на оба remote main, обнаружены `.env` с рабочими ключами Fernet и зашифрованные базы серверов. Один непустой архив из текущего HEAD удалось расшифровать историческим ключом: четыре записи, адреса, имена и поля учётных данных. Пустой файл серверов также расшифровывается. Второй архив проверенными ключами не расшифрован — это не доказательство безопасности остальных исторических версий.

Текущий локальный ключ присутствовал в исходной истории. Дополнительно подтверждено расшифрование 11 вложенных полей учётных данных историческими ключами (это число полей, а не уникальных паролей). Расшифрованные значения не включены в отчёт и не отправлены сторонним сервисам. Временный локальный список значений для git-filter-repo удалён после очистки. Приватная резервная копия исходной истории сохранена. Факт доступа посторонних не проверялся; публичная доступность достаточна, чтобы считать доступные секреты раскрытыми.

## Исправления рабочей ветки

- Три базы `.enc` и локальные заметки `data/hints.json` удалены только из индекса Git. Локальные файлы сохранены.
- Добавлены правила исключения баз, заметок, файлов окружения и credential-файлов.
- Windows-установщик получает пустой шаблон заметок и не перезаписывает заметки пользователя при обновлении.
- macOS-сборка больше не включает всю локальную папку `data`.
- Добавлен `.dockerignore`, чтобы личные данные не попадали в Docker build context.
- Перед Windows-сборкой проверяются запрещённые пути в индексе Git и каталогах, включаемых в установщик.

## Выполненная очистка истории

С разрешения владельца переписаны и проверены по удалённым хешам 31 ссылка веток/тегов GitHub и 26 ссылок Forgejo. Удалены 14 исторических путей с файлами окружения, конфигурацией, базами, заметками и загрузками. Дополнительно заменены копии пяти известных ключей, 11 обнаруженных значений реквизитов и четырёх адресов. В 2915 объектах проверенных веток/тегов совпадений с этими значениями не осталось.

Для GitHub main временно разрешался force push; после отправки запрет восстановлен и проверен. Остальные правила защиты не изменялись. Рабочие локальные ветки/теги переведены на очищенную историю. Незакоммиченная разработка 4.9.0 не публиковалась. Локальные данные сохранены; исходная история хранится только в игнорируемой приватной резервной копии, которая тоже содержит раскрытые данные и не предназначена для публикации.

Это не означает полного удаления всех публичных копий. GitHub продолжает рекламировать 45 служебных ссылок старых PR: 22 подтверждённо относятся к изменённым коммитам, ещё 23 не классифицированы локальной картой. Их и кэшированные представления может очищать GitHub Support. Подготовлен приватный черновик обращения без секретных значений. Обращение не отправлялось.

В GitHub Releases обнаружены старые бинарные вложения двух macOS-релизов и одного Windows-релиза. Переписывание Git не меняет эти файлы; содержимое опубликованных бинарников пока не проверено, они не удалены. Новая локальная Windows-сборка использует исправленные правила упаковки.

## Необходимые следующие действия

1. Сменить реальные пароли SSH/панелей, токены и другие реквизиты из раскрытого архива. Не считать шифрование второго уровня гарантией защиты при опубликованном ключе.
2. Сохранить приватную резервную копию и перешифровать локальные базы новым ключом. Простая замена SECRET_KEY в `.env` лишит доступа к старым данным; её делать нельзя.
3. Обратиться в GitHub Support для удаления старых PR-ссылок и кэша. Остальные старые клоны следует заменить чистыми; слияние старой истории вернёт удалённые данные. Текущая рабочая копия уже согласована с очищенной историей.
4. Проверить старые релизные артефакты: Windows ранее включал локальные заметки, macOS — каталог данных. Локально проверены правила упаковки; опубликованные бинарники и удалённые форки не исследованы.

Проверка текстовых примеров не обнаружила прежний личный домен в текущих исходниках. Найденные литералы паролей относятся к учебным примерам/тестам, сетевые диапазоны — к примерам и сетевой классификации. Публичное имя автора и ссылки на его репозиторий сохранены как метаданные проекта. Изображения/OCR и все исторические blob-объекты не сканировались; абсолютная гарантия отсутствия иных данных не заявляется.
