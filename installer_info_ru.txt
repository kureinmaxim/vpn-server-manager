VPN Server Manager

Локальное приложение для тех, кто сам держит VPN-серверы.
Зашифрованная картотека, мониторинг по SSH и PIN-блокировка.
Облачный аккаунт не нужен.

Требования
- Python 3.13 или новее
- Этот установщик копирует файлы программы. После установки при
  первом запуске выполните setup_windows.bat (создаст виртуальное
  окружение и поставит пакеты).

Данные серверов остаются на этом компьютере. Сохраните резервную
копию ключа шифрования из файла .env. Без ключа хранилище
восстановить нельзя.
