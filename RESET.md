# Очистка TelegramOnly из карточки сервера

Экспериментальная ветка: `codex/experimental-telegramonly-reset`.
Кнопка **«Очистить стек»** находится рядом с Status и Monitoring в компактной
и полной карточке сервера. Удаление карточки и очистка VPS — разные действия.

1. Проверьте прямой публичный IP и SSH-доступ. Откройте Status / Monitoring.
2. Нажмите «Очистить стек» и выберите только установленные вами компоненты.
3. Запросите план: этот этап ничего не удаляет.
4. Проверьте службы, пути, контейнеры, тома и блокировки.
5. Введите точный hostname из плана и подтвердите очистку.
6. Дождитесь результата и сохраните путь закрытого архива на VPS.

План привязан к выбранному серверу и текущему сеансу, действует 10 минут и
при выполнении используется один раз. Требуются PIN и CSRF-токен. SSH host key
должен быть проверен и сохранён в `~/.ssh/known_hosts` пользователя приложения:
подключитесь обычным OpenSSH и сверьте fingerprint с консолью провайдера.
Tabby может хранить ключи отдельно. Не отключайте проверку host key.
На VPS нужны root либо существующее разрешение `sudo -n` для Python, Python 3,
Debian/Ubuntu, systemd и findmnt. Сценарий передаётся по SSH из приложения;
обновлённый TelegramOnly на VPS не требуется. После изменения Python-кода
перезапустите приложение; для установленного exe соберите новую версию.

Останавливаются выбранные известные службы, убираются Compose-контейнеры
TelegramOnly. Файлы переносятся в `/var/backups/telegramonly-reset/`, а
эксклюзивные named volumes архивируются перед удалением. Общие тома, чужие
контейнеры с зависимостями и небезопасные пути блокируют reset. Нестандартные
пути и установки автоматически не удаляются.

Debian, SSH, ключи, firewall, маршруты, Docker engine/images и общие системные
пакеты остаются. Tailscale/Headscale/Headplane и мониторинг сохраняются.
Это сброс выбранного стека, а не восстановление исходного состояния ОС.
Подключайтесь по прямому IP, не через очищаемый прокси.

Архив содержит секреты, доступен root и не должен попадать в Git. При ошибке
часть служб может уже быть остановлена: откройте SSH и проверьте manifest.json.
При потере ответа повторная очистка не запускается автоматически. Удалённые
контейнеры восстановите из сохранённого Compose; файлы — из files/, тома —
из tar по manifest. Сначала сохраните новые данные. Автоматического отката нет.

Полная инструкция Tabby и повторной установки находится в корневом RESET.md
проекта TelegramOnly; канонический движок — scripts/reset_telegramonly.py.
Его копия встроена в app/services/reset_payload.py. При изменении движка
обновляйте копию и запускайте тесты обеих реализаций. На реальной VPS
разрушительный этап в ходе разработки не выполняется.
