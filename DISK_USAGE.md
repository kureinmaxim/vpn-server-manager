# Проверка места на VPS

В карточке сервера выберите **Действия → Проверить место на диске**.
Страница показывает команды `du` и `journalctl --disk-usage`.
**Копировать команды** копирует их для вставки в Tabby.
**Выполнить на этом VPS** запускает фиксированные команды через SSH из карточки и показывает результаты.
Проверка ничего не удаляет и не меняет. Для root sudo не используется, для других пользователей нужен sudo без запроса пароля.
Отсутствие архива после удаления нормально: результат может содержать замечание о недоступном каталоге.
